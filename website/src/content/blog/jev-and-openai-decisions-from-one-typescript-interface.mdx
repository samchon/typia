```typescript
import typia from "typia";

enum Department {
  /**
   * Payments, invoicing, refunds.
   *
   * Duplicate charges, failed cards, and plan changes belong here, even when
   * the customer also mentions a bug.
   *
   * @probability 0.3
   */
  billing = "billing",

  /**
   * Bugs, outages, and broken integrations.
   *
   * Paging an engineer is expensive, so only pick this when the customer
   * describes the product misbehaving.
   *
   * @probability 0.5
   */
  technical = "technical",

  /**
   * Pricing, upgrades, and new accounts.
   *
   * @probability 0.2
   */
  sales = "sales",
}

interface ITicketTriage {
  /**
   * Does the customer convey urgency?
   *
   * A deadline, an outage, lost revenue, or a threat to leave counts. An
   * impatient tone alone does not.
   */
  urgent: boolean;

  /**
   * Which team should handle this ticket?
   *
   * Decide by what the customer needs done, not by the words they use.
   */
  department: Department;

  /**
   * Does the customer ask for their money back?
   *
   * Complaining about a charge is not a request. The customer has to ask.
   *
   * @probability 0.8
   */
  refund: boolean;
}

const triage = typia.llm.evaluation<ITicketTriage>();
```

`triage.questions` goes to the model. `triage.decode()` turns its answer into `ITicketTriage`.

## Jev

```typescript
import { TypeSafeClient } from "@typesafe-ai/sdk";
import { toJevQuestions } from "@typia/jev";

const client = new TypeSafeClient(); // reads TYPESAFE_API_KEY
const { answers } = await client.systemOne({
  model: "jev-1.13.0",
  state: "I was charged twice this morning. Refund it now, or I leave.",
  questions: toJevQuestions(triage.questions),
});

const result = triage.decode(answers);
if (result.success) {
  result.data.department; // Department
  result.data.refund; // boolean
}
```

## OpenAI

```typescript
import { openai } from "@ai-sdk/openai";
import { experimental_evaluate } from "ai";

const result = await experimental_evaluate({
  model: openai.evaluationModel("gpt-5.6-luna"),
  state: ticket,
  questions: triage.questions,
});
const decoded = triage.decode(result.answers);
```

Swap in `typeSafeAi.evaluationModel("jev-1.13.0")` from `@ai-sdk/typesafe-ai` and it's Jev again.

OpenAI writes each number itself and returns no per-option probabilities, so `@probability` on `department` always fails there. The boolean ones work.

## Thresholds

`technical` picked at 0.45 is the model's top choice, and still under its 0.5:

```json
{
  "success": false,
  "errors": [
    {
      "path": "$input.department",
      "description": "\"technical\" has probability 0.45 < 0.5."
    }
  ]
}
```

It fails. It never falls back to the runner-up.

## Get it

```bash
npm install typia @typia/jev @typesafe-ai/sdk
npm install -D ttsc typescript

npx ttsc            # build
npx ttsx src/index.ts   # run
```

It has to be `ttsc` and `ttsx`. Plain `tsc` and `tsx` can't apply the transform.
